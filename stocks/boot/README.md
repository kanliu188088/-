# 把看盤儀表板設成開機畫面

儀表板：https://claude.ai/artifact/26V5pEmZoJMCHDeNWGMHSW

## Windows 電腦
1. 下載 `台積電看盤-開機啟動.bat`。
2. 按 `Win + R`，輸入 `shell:startup`，按 Enter。
3. 把 .bat 檔放進打開的「啟動」資料夾。
4. 重新開機：約 15 秒後儀表板會以全螢幕打開。按 `Alt + F4` 關閉。
5. 不想再自動打開時，把 .bat 從「啟動」資料夾刪掉。

第一次請先用 Edge 或 Chrome 登入 claude.ai，開機打開時才不用再登入。

## 手機
- iPhone（Safari）：打開連結 → 分享按鈕 → 「加入主畫面」。
- Android（Chrome）：打開連結 → 右上角 ⋮ → 「加到主畫面」。
圖示放在主畫面第一頁，解鎖就看得到。

## 給朋友同學看
儀表板預設只有自己看得到。在儀表板右上角的「分享」選單開放，朋友才打得開連結。
