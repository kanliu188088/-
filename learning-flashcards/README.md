# 精華速學卡

給它一個**題目**、一段**文章**或一個**網址**，它會用「精華速學法」產生一份限時學習計畫，並把最重要的內容做成閃卡。

## 精華速學法（五步）

1. **80/20 抓核心**：只挑能解釋大部分內容的 3–5 個核心概念。
2. **費曼白話＋類比**：每個概念用國中生聽得懂的話解釋，配一個生活類比。
3. **框架**：把概念串成一個心智模型（因果、流程或層級）。
4. **主動回想**：自我測驗題，先想再看答案。
5. **間隔重複**：問答閃卡，「再一次」的卡會在 3 張之後重新出現，直到全部記住。

另外會列出常見誤解與可以立刻動手的應用練習。學習時間可選 15 / 30 / 60 分鐘。

## 用聽的（朗讀）

- **朗讀這一面**：唸出目前看到的問題或答案。
- **聽卡模式**：自動唸問題 → 留思考時間（3 / 5 / 8 / 12 秒）→ 翻面唸答案 → 下一張，一輪聽完自動停止。適合通勤、走路時複習。
- 可調整語速與聲音，會優先選用台灣中文（zh-TW）語音。使用瀏覽器內建語音，不需網路服務；建議用 Chrome、Edge 或 Safari。

## 電子書（EPUB）

每個牌組都能按「下載電子書（EPUB）」匯出，內容包括學習計畫、每張閃卡（問題一頁、答案在下一頁）以及書末速查表。

- iPhone：用 Apple Books 開啟。
- Android：用 Google Play 圖書開啟。
- 閱讀器內建的朗讀功能也能把電子書唸給你聽。
- 電子書在程式內直接產生，不需要網路，已通過 EPUBCheck 5.3 驗證。

## 使用方式

- **在 claude.ai 中開啟**（Artifact 版本）：用你自己的 Claude 帳號產生內容，不需要 API 金鑰。這個環境無法開網頁，網址模式請貼上網頁內文。
- **直接用瀏覽器開啟 `index.html`**：輸入 Anthropic API 金鑰即可使用（金鑰只存在你的瀏覽器）。網址模式會讓 Claude 直接讀取該網頁。

牌組存在瀏覽器的 localStorage，可用「複製成 Anki 匯入格式」匯出（Tab 分隔：正面、背面、標籤）。
